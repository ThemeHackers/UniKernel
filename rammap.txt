================================================================================
Memory Optimization Techniques Used
================================================================================

1. STATIC ALLOCATION ONLY
   - No malloc/free calls
   - No heap fragmentation
   - Predictable compile-time memory usage

2. FIXED-SIZE BUFFERS
   - inputBuffer[48]     : Limited command line length
   - content[16]         : Small file contents only
   - name[10]            : Short filenames (9 chars max)
   - PATH_LEN = 12       : Short paths

3. STACK DISCIPLINE
   - MAX_SHELL_DEPTH = 3 : Prevent stack overflow
   - Limited recursion in scripts
   - Shallow call chains

4. PROGMEM FOR STRINGS
   - F() macro for string literals
   - Saves ~500+ bytes RAM
   - Slower access but acceptable

5. BITWISE STRUCT PACKING
   - flags field: uint8_t with bitmasks
   - FLAG_ACTIVE = 0x01
   - FLAG_ISDIR  = 0x02
   - Multiple booleans in 1 byte

6. EEPROM OFFLOADING
   - Password hash stored in EEPROM (512)
   - Salt stored in EEPROM (530)
   - Lockout time in EEPROM (522)
   - Saves RAM for non-volatile data
